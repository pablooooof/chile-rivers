03 Key Observations

Chile Rivers already outperforms most sites in regulation depth. No other free site combines per-waterbody regulation citations, season visualization, gear advisories, and transport planning in a single map. Quebec's government map is the closest in regulation quality, but lacks transport or advisory layers. Most platforms trade regulation accuracy for social/community features.

Gaps that matter

Search and filter — every comparable site lets you search by waterbody name or filter by species. Chile Rivers has neither. This is the most common workflow: "where can I fish for brown trout right now?"

Offline access — Patagonia has poor cell coverage. onX Fish, Angler's Atlas, and FishMap all offer offline maps. A service worker / PWA approach would let anglers cache the map before a trip.

Community layer — Fishbrain and FishMap prove that catch reports and trip logs create retention. But these require backends, moderation, and ongoing cost — the opposite of a free static site. A lighter approach: curated "fishing reports" or links to community forums.

Weather context — Fishbrain and FishMap show weather at each spot. Free APIs (Open-Meteo) could add current temperature, wind, and river flow to the detail panel with no cost.

What Chile Rivers does uniquely

Regulation traceability — citing specific Sernapesca/Subpesca resolutions by waterbody. No other free site globally does this at the individual river level.

Transport integration — bus terminals and airports with travel times/prices from Santiago. Only PiscaMaps attempts trip logistics, and not as cleanly.

Season timeline visualization — the visual bar showing C&R → harvest → closure phases with a "today" marker. Unique across all sites reviewed.

04 Roadmap — Prioritized To-Do List

Ordered by impact vs. effort, keeping the project free and static-first.

Tier 1 — High impact, low effort
Search by waterbody name
LOW EFFORT HIGH IMPACT
Add a search input that filters the loaded GeoJSON features by name. Auto-complete dropdown, fly-to on select. Already have the data client-side — no backend needed.
See: Quebec map, AnglerFinder, Fishbrain — all have search-first UX
Filter by species
LOW EFFORT HIGH IMPACT
Species presence data already exists in advisory.json. Add chip-style toggles (rainbow trout, brown trout, chinook, coho, etc.) that filter visible waterbodies on the map.
See: Hooked Ontario, FishMap — species chips above the map
Filter by "open now" status
LOW EFFORT HIGH IMPACT
Toggle to show only waterbodies currently open for fishing (C&R or harvest). Season data is already computed — wire it to a map filter expression.
See: Quebec map's regulatory grid — anglers want "what's open right now?"
URL deep-links to individual waterbodies
LOW EFFORT MED IMPACT
Update the URL hash when a waterbody is selected (#rio-petrohue). On page load, parse the hash, fly to the feature, and open the panel. Enables sharing specific rivers.
See: AnglerFinder deep-links, Quebec map's bookmark feature
Tier 2 — High impact, moderate effort
PWA / offline mode
MED EFFORT HIGH IMPACT
Add a service worker to cache the app shell + GeoJSON. Anglers in Patagonia lose signal on the river. Pre-cache map tiles for the covered region at useful zoom levels.
See: onX Fish offline maps, Angler's Atlas offline sync — critical for remote areas
Weather & river conditions
MED EFFORT HIGH IMPACT
Show current temperature, wind, precipitation in the detail panel using Open-Meteo (free, no API key). Optionally pull river flow from DGA (Dirección General de Aguas) if data is available.
See: FishMap live weather, Fishbrain BiteTime — weather is the #1 trip-day question
Expand geographic coverage
MED EFFORT HIGH IMPACT
Extend north to Biobío, Maule, O'Higgins, and Metropolitana (already started with Araucanía and Metropolitana YAML). Every new region multiplies the user base.
See: AnglerFinder (all 50 states), PiscaMaps (10 countries) — completeness drives adoption
Nearby services layer
MED EFFORT MED IMPACT
Toggleable layer for fly shops, fishing guides, lodging, campgrounds near each waterbody. Source from Overpass (tourism=camp_site, shop=fishing) or curate manually.
See: Fishbrain (tackle shops/marinas), PiscaMaps (nearby camping links)
Access points & wading spots
MED EFFORT MED IMPACT
Mark boat ramps, bridge crossings, and known wading access along each river. Overpass can supply leisure=slipway and highway=ford. Community can contribute missing ones via GitHub issues.
See: AnglerFinder (access per spot), onX Fish (public access points)
Mobile-first responsive redesign
MED EFFORT MED IMPACT
Panel as a bottom sheet on mobile (like Google Maps), swipe-to-expand. Current sidebar overlaps the map on narrow screens. Add "Add to Home Screen" PWA prompt.
See: Fishbrain, FishMap — mobile is 70%+ of fishing app traffic
Tier 3 — Ambitious, higher effort
Community fishing reports (static)
HIGH EFFORT HIGH IMPACT
Accept trip reports via GitHub Discussions or a Google Form. A build step aggregates approved reports into a JSON file. No backend, stays free — moderation through PR review. Show recent reports on each waterbody's panel.
See: Fishbrain community, FishMap catch log — but adapted for a static site
Fishing license guide by region
LOW EFFORT MED IMPACT
Add a panel section or standalone page explaining how to get a fishing license in Chile (Sernapesca online, costs, requirements for foreigners). Link to official purchase page.
See: AnglerFinder license guide, Japan's Tsurichike permit system
Favorites / bookmarks (local storage)
LOW EFFORT MED IMPACT
Let users star waterbodies; store in localStorage. Add a "My spots" view that lists bookmarked rivers/lakes with their current status. No login needed.
See: Quebec bookmarks, PiscaMaps shortlist, Fishbrain waypoints
Print-friendly regulation summary
LOW EFFORT MED IMPACT
A print stylesheet or "Download PDF" for the detail panel. Anglers heading to areas without signal want to print regulations for the rivers they plan to fish.
See: Quebec map's print functionality — offline reference when cell signal dies
River flow / water level data
HIGH EFFORT MED IMPACT
Pull gauge data from DGA's hydrometric stations (if API exists) or scrape published readings. Show current flow level and a 7-day sparkline in the detail panel.
See: USGS river flow gauges — the gold standard for river fishing planning
Portuguese (PT-BR) language
MED EFFORT MED IMPACT
Brazil has a large fly-fishing community that travels to Patagonia. Adding Portuguese would tap a major visiting-angler audience with the existing i18n system.
See: FishMap (5 languages), PiscaMaps (multi-country) — language unlocks international users
Open data portal
MED EFFORT LOW IMPACT
Publish waterbodies.geojson and regulation data with a clear license (CC BY-SA). Add an API documentation page. Other developers and researchers can build on top.
See: AnglerFinder GeoJSON export, Angler's Atlas citizen-science data sharing

05 Staying Free — How Others Do It

The free-and-sustainable models from this research:
FishMap (Scandinavia) — built by a solo developer, donation-supported, no corporate backing. Closest to Chile Rivers' ethos.
AnglerFinder — free with curated content; revenue from ads and affiliate links to gear retailers.
Quebec / Ontario maps — government-funded public service; Chile's Sernapesca could theoretically partner.
Angler's Atlas — free for anglers; monetizes through conservation research partnerships and tournament hosting.
PiscaMaps — free with optional premium features; core map and regulation data always free.

For Chile Rivers, the FishMap model is the most aligned: free and open-source, donation link for those who want to support, community contributions through GitHub. Affiliate links to local fly shops or guides could generate small revenue without compromising the free mission. A Sernapesca partnership (linking official data) would add legitimacy.
